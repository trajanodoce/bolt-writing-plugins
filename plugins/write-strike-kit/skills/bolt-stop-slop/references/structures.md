# Structures to avoid

## Binary contrasts / negation-reframes

These create false drama. State the positive claim directly.

| Pattern | Problem |
|---------|---------|
| "Not because X. Because Y." / "Not because X, but because Y." | Telegraphed reversal |
| "[X] isn't the problem. [Y] is." | Formulaic reframe |
| "The answer isn't X. It's Y." | Predictable pivot |
| "It feels like X. It's actually Y." | Setup/reveal cliche |
| "The question isn't X. It's Y." | Rhetorical misdirection |
| "Not X. But Y." / "not X, it's Y" / "isn't X, it's Y" | Mechanical contrast |
| "It's not this. It's that." | Same formula, different words |
| "stops being X and starts being Y" | False transformation arc |
| "doesn't mean X, but actually Y" | Negation-then-assertion crutch |
| "is about X but not Y" | False distinction |
| "not just X but also Y" | Additive hedge |
| "Forget X. This is Y." | Same formula, imperative version |
| "Less X, more Y." | Comparative version |

**Fix:** State Y. "The problem is Y." Drop the negation.

## Negative listing

Listing what something is *not* before revealing what it *is*.

| Pattern | Problem |
|---------|---------|
| "Not a X... Not a Y... A Z." | Dramatic buildup through negation |
| "It wasn't X. It wasn't Y. It was Z." | Same structure, past tense |

**Fix:** State Z. The reader doesn't need the runway.

## Dramatic fragmentation

Sentence fragments for false emphasis.

| Pattern | Problem |
|---------|---------|
| "[Noun]. That's it. That's the [thing]." | Performative simplicity |
| "X. And Y. And Z." | Staccato drama |
| "This unlocks something. [Word]." | Artificial revelation |

**Fix:** Complete sentences. Trust content over presentation.

## Rhetorical setups

Announcing insight rather than delivering it.

| Pattern | Problem |
|---------|---------|
| "What if [reframe]?" | Socratic posturing |
| "Here's what I mean:" | Redundant preview |
| "Think about it:" | Condescending prompt |
| "And that's okay." | Unnecessary permission |
| "Once you see it this way, you can't unsee it." | Setup-payoff cliche |
| "There's a thought experiment that changes..." | Same |
| "What isn't measured doesn't improve." | Aphorism as argument |

**Fix:** Make the point. Let readers draw conclusions.

## Formulaic constructions

| Pattern | Problem |
|---------|---------|
| "By the time X, I was Y." | Narrative template |
| "X that isn't Y" | Indirect. Say "X is broken" |

## False agency

Inanimate things doing human verbs. AI uses this to avoid naming the actor.

| Pattern | Problem |
|---------|---------|
| "a complaint becomes a fix" | Someone fixed it |
| "a bet lives or dies in days" | Someone kills or ships it |
| "the decision emerges" | Someone decides |
| "the culture shifts" | People change behavior |
| "the conversation moves toward" | Someone steers |
| "the data tells us" | Someone reads it and draws a conclusion |
| "the market rewards" | Buyers pay for things |

**Fix:** Name the human. "The team fixed it" beats "the complaint becomes a fix." Use "you" when no specific person fits.

## Narrator-from-a-distance

Floating above the scene.

| Pattern | Problem |
|---------|---------|
| "Nobody designed this." | Disembodied observation |
| "This happens because..." | Lecturer voice |
| "This is why..." | Same |
| "People tend to..." | Armchair sociologist |

**Fix:** Put the reader in the room. "You" beats "People."

## Superficial -ing analyses

Present-participle phrases bolted onto sentence ends to fake depth.

| Pattern | Problem |
|---------|---------|
| "..., highlighting the importance of X" | Analysis-shaped filler |
| "..., underscoring its commitment to Y" | Significance announced, not shown |
| "..., reflecting a broader trend" | Unearned generalization |
| "..., showcasing / symbolizing / emphasizing..." | Decorative depth |

**Fix:** End the sentence at the fact. If the significance is real, give it its own sentence with a specific, checkable claim.

## False ranges

"From X to Y" pairs that fake breadth with endpoints that aren't on a real scale.

| Pattern | Problem |
|---------|---------|
| "from startups to Fortune 500s" | Fake spectrum standing in for "two customer types" |
| "from marketing to engineering and beyond" | "And beyond" = nothing |
| "everything from A to Z" | Vague totality |

**Fix:** Name the actual set, or give the two or three real examples.

## Synonym cycling (elegant variation)

Rotating synonyms to dodge repeating a word: developers → engineers → practitioners → technologists in one passage.

**Fix:** Pick the right word and repeat it. Repeating the correct term is clarity, not a flaw. Humans vary words occasionally and deliberately; AI does it compulsively.

## Formulaic conclusions

| Pattern | Problem |
|---------|---------|
| "Despite these challenges, X continues to..." | Challenges-then-reassurance template |
| "As X evolves, Y will play an increasingly important role" | Future-outlook boilerplate |
| A closer restating the piece ("In conclusion / Overall...") | Compulsive summary |

**Fix:** End on your strongest specific point. If long-form genuinely needs a summary, summarize the argument, not the structure.

## Significance inflation

Monumentalizing the mundane. Cousin of copula inflation (see SKILL.md §3).

| Pattern | Problem |
|---------|---------|
| "stands as a testament to" | Unearned monument |
| "marks a pivotal moment / a key turning point" | History-making without history |
| "left an indelible mark" | Same |
| "plays a vital/crucial role in" | Importance announced, not shown |

**Fix:** State what it did, with a number, a name, or a consequence. Real significance survives specifics; fake significance needs the phrasing.

## Overly smooth connectors

Paragraph openers that create artificial flow between sections.

- "This belief defines how we build Bolt.new."
- "This is personal for us."
- "These qualities embody our team."
- "That same pattern shows up across the team."

**Fix:** If the paragraph follows logically, it doesn't need a connector. Cut it.

## Passive voice

Every sentence needs a subject doing something.

| Pattern | Fix |
|---------|-----|
| "X was created" | Name who created it |
| "It is believed that" | Name who believes it |
| "Mistakes were made" | Name who made them |
| "The decision was reached" | Name who decided |

## Sentence starters to avoid

| Pattern | Fix |
|---------|-----|
| Wh- word openers (What, When, Where, Which, Who, Why, How) | Restructure. Lead with the subject or verb. |
| Paragraphs starting with "So" | Start with content |
| Sentences starting with "Look," | Remove |

## Rhythm patterns

| Pattern | Fix |
|---------|-----|
| Three-item lists | Default to two items |
| Questions answered immediately | Let questions breathe or cut them |
| Every paragraph ends with a punchy one-liner | Vary endings |
| Em dashes | Remove. Use commas, periods, colons, semicolons, or parentheses. |
| Stacked short punchy sentences | Don't stack more than two |
| "Not always. Not perfectly." | Hedging disguised as reassurance |

## Word patterns

| Pattern | Problem |
|---------|---------|
| Lazy extremes (every, always, never, everyone, everybody, nobody) | False authority. Use specifics instead of sweeping claims. |
| All adverbs (-ly words, "really," "just," "literally," "genuinely," "honestly," "simply," "actually") | Empty emphasis. See references/banned.md for the full list and the vocabulary tiers. |
