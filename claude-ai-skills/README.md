# claude.ai upload copies

Verbatim copies of the live skills (paths unmodified). Pull from HERE when
updating the claude.ai skill library (Settings -> Capabilities), which runs
skills locally where `~/.claude/skills/` paths resolve.

Do NOT upload from `plugins/`: those copies use `${CLAUDE_PLUGIN_ROOT}`
paths that only resolve inside a Claude Code plugin install.

Regenerated by `build.py` on every deploy; never edit here.
